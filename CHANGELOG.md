# Changelog

## 1.0.0

First release.

- Menu bar battery pill with live wattage (battery gauge read once a second).
- Battery dropdown: health, temperature, power and electrical, power flow, charger profile, capacity, lifetime stats, apps using significant energy, connected device batteries.
- Daily battery-health record and charge / on-battery session log with CSV export.
- Stats-style modules: CPU, GPU, memory, disk, network, sensors, fans, Bluetooth, clock. Per-module menu bar widgets, or merge them into one item.
- Dashboard window with a detailed page per module.
- Reorderable and hideable dropdown sections.
- Animated on-screen alerts (plug-in, unplug, low, critical, fully charged, charge limit) and threshold notifications.
- Optional core sensors helper (admin, once) for CPU / GPU / Neural Engine watts, frequencies and thermal pressure.
- Single-instance behaviour: a newly launched copy replaces any older one.
- DMG installer with a drag-to-Applications window, plus a zip.
